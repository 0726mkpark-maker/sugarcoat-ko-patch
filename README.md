# 『Sugar,sugar,sugarcoat』 비공식 한국어 패치

**[v1.0.0 다운로드 및 설치 안내](https://github.com/0726mkpark-maker/sugarcoat-ko-patch/releases/tag/v1.0.0)**

제작자의 허락을 받아 무료·비영리로 배포하는 **비공식 한국어 번역 패치**입니다. 공식 한국어판 또는 공식 번역이 아닙니다.

- 작품: **『Sugar,sugar,sugarcoat』**
- 원작 제작: **小鳩えん / パンくず工房**
- 패치 제작·검수·작동 확인·문의 대응: **パク (0726mkpark-maker)**
- 지원 대상: **정식으로 구매·설치한 Windows 64비트 Steam판, 게임 버전 1.1.4**

## 설치

1. [릴리스 페이지](https://github.com/0726mkpark-maker/sugarcoat-ko-patch/releases/tag/v1.0.0)의 **SUGAR_KO_PATCH_v1.0.0.zip**을 다운로드하고 새 폴더에 모두 압축 해제합니다. `Source code` 파일은 설치용 패키지가 아닙니다.
2. 게임을 종료한 뒤 **Install.cmd**를 실행합니다.
3. Steam 라이브러리에서 게임 우클릭 → **관리 → 로컬 파일 탐색**으로 설치 폴더를 엽니다. 탐색기 주소 표시줄의 주소를 복사해 설치창에 붙여넣고 **설치**를 누릅니다. **찾아보기**로 지정해도 됩니다.
4. `Completed.`가 표시되면 게임을 실행합니다. 시작 시 언어 선택 화면 또는 **Config**에서 **한국어**를 선택할 수 있습니다.

별도 프로그램 설치는 필요 없습니다. 지원 대상과 다른 게임 버전에는 설치할 수 없습니다.

## 제거·재설치

게임을 종료한 뒤 **Uninstall.cmd**를 실행해 같은 설치 폴더를 지정합니다. 게임 원본과 저장 데이터는 삭제하지 않습니다. 재설치는 **Install.cmd**, 설치 도중 중단된 경우의 복구는 **Recover.cmd**를 사용하세요.

## 이용 조건·권리 안내

- 정식 게임의 구매 및 설치가 필요하며, 이 패치만으로는 게임을 실행할 수 없습니다.
- 무료·비영리로 배포합니다. 패치 자체를 이용한 판매, 유료 제공 등 수익 창출을 금지합니다.
- 게임 본체·실행 파일·음악·음성 등을 재배포하지 않습니다. 번역 데이터와 실행에 필요한 최소한의 차분을 배포하며, 필요한 원본 자산은 이용자가 설치한 정품 게임에서 사용합니다.
- 원작과 게임 자산의 권리는 **小鳩えん / パンくず工房** 및 각 권리자에게 있습니다.
- 게임 업데이트로 문제가 발생하거나 원작 제작자가 수정·공개 중지를 요청하면 패치 제작자가 필요한 수정·배포 중지 등에 대응합니다.
- 한국어 폰트 **x12y12pxMaruMinyaHangul**은 **SIL Open Font License 1.1**을 따릅니다. 원문 라이선스와 구성 요소별 안내를 ZIP에 동봉했습니다. 폰트의 OFL 권리는 패치의 비영리 배포 조건과 별개로 유지됩니다.
